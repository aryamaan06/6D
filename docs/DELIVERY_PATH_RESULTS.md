## Delivered

paths. Calculated metrics, declared limits and refinement-grid comparisons have
distinct roles, so the model cannot substitute a different valid fact as a limit.

values are withheld from that commentary wire context with a disclosure; full
values remain saved and visible in deterministic evidence views. This deliberately
narrows what the AI is asked to do. It does not prove general semantic correctness.

constructed reference project, calculate its baseline, edit a draft, preview the
impact, save a revision, rerun affected checks and export the evidence. It follows
real revision/run states; opening it does not save, calculate or call a model.
