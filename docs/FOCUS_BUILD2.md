1. Enter a finite positive thrust in **newtons (N)** and a source or rationale. If multiple thrust inputs are bound, select the one to edit.
2. Select **Stage thrust change**. This previews dependencies and stages the shared draft; it does not save a revision or calculate a result.
3. Review the changes, then choose **Save revision**.
4. Explicitly run the saved revision's checks to record its new findings.
