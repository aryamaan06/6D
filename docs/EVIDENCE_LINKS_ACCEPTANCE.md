# Evidence-linked Assistant milestone

Acceptance written before implementation, October 20, 2026.

An engineer opens a saved investigation, inspects the calculated criterion and
grid evidence, follows a numerical reference to its exact captured source, and
identifies a concrete next engineering check without confusing AI prose with a
calculated result.

Required checks:

- Facts copy selected metric/limit, input, numerical-refinement and selected-test
  values from captured records. Each reference binds the project, revision, run,
  review, requirement, model, source digest and JSON pointer.
- Grid labels and values stay together. The 512→1024 and 1024→2048 differences
  cannot be substituted by copying a bare value into a new explanation.
- New explanations use application-rendered fact references for numbers. Unknown
  references, changed catalogs and numeric literals outside references are
  rejected. These are bounded checks, not complete semantic verification.
- The facts view remains useful without a live connection. Historical text,
  failures, reviews and comparison scores remain unchanged; derived historical
  facts are labelled as a current read-only projection.
- Links open captured evidence, even when the workspace has moved to another
  revision. All displayed text is escaped; keyboard navigation works.
- Existing grounded next checks remain visible. An unmet criterion, unassessed
  coverage, numerical agreement and physical validity remain distinct.
- A separate three-case Nano/Super/Ultra plan uses identical saved evidence,
  records actual completion/rejection/cost/latency, and cannot change selection.
  Paid work requires explicit start and a private connection. Proposed batch
  ceiling: USD 2 inside the existing USD 29.50 cumulative allowance; no card spend.
- Current selection, configuration, original workspace rows and existing spending
  reservations are preserved. Verification uses isolated stores and no paid calls.

Catalog scope deliberately excludes full time histories and arbitrary source
prose. Other evidence remains available in captured JSON. A referenced value is
traceable; an AI interpretation still requires engineering review.
