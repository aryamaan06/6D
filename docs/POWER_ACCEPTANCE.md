## Implemented contract

The maintained `power_energy_budget` adapter calculates supplied sequential constant operating modes. Equipment counts declare continuous simultaneous loads within each mode. Exact `W`, `J`, `s` and dimensionless count bindings use the existing scalar project schema; no arbitrary model code or project-level mode metadata is added. Upfront usable battery energy is bus-deliverable energy already adjusted by the author for reserves and losses. Generation surplus is reported without recharge credit.

Power capacity and energy sufficiency remain separate metrics and declared requirement findings. Budget shortfalls remain completed calculations with `not_met` findings when the explicit criterion is violated. Invalid inputs, incompatible units or unsupported metric mappings remain unassessed. No solar, battery state-of-charge, electrical transient, duty-cycle or automatic model-coupling capability is implied.

Completed results retain the ordered mode/equipment artifact, capacities, cumulative arithmetic, assumptions and exclusions in saved run and review evidence. The existing draft/revision, targeted rerun/reuse, systems/interface projection, scenario, scalar test-comparison and scoped-investigation contracts accept the new model. Historic canonical and original test records are not rewritten. See [POWER_ENERGY.md](POWER_ENERGY.md) for equations, exact flat binding roles, units, bounds, supported metrics, reference arithmetic and numerical limits.
