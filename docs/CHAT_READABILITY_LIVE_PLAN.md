- Protocol completion: required reads/recheck, accepted final output, intact receipt and matching parent context on the follow-up.
- Evidence checks: application-owned criterion/values/directions remain authoritative and unchanged; existing interpretation guards stay enabled.
- Readability review: first answer explains the meaning plainly; second resolves the reference and offers a specific next check. A generic status repetition alone is not a useful answer.
- Report actual attempts, accepted responses, job states, elapsed time and reservation delta for each model. Separate human/agent qualitative review from machine guard acceptance.
