# Build E acceptance: remembered optional connections

Acceptance recorded before implementation completion on October 25, 2026. The approved scope is optional remembered Tavily and LangSmith connections on this Windows device, extending the existing Nebius connection without changing project engineering evidence or provider allowances.

- Remember is an explicit unchecked option for each service. Ordinary connects remain session-only. Windows current-user DPAPI protects remembered credentials; no plaintext or browser-storage fallback is permitted. The interface explains this account/device scope without claiming production or team security.
- Preserve the existing Nebius remembered-key path, ciphertext header, schema and encryption entropy. A blob written before E still restores through the existing Nebius path; no migration or key re-entry is required solely by this change.
- Save each optional service independently with an explicit service/schema identity and its required validated metadata inside the protected payload. Tavily restores its absolute local credit limit; LangSmith restores its US/EU region and optional workspace UUID. A wrong service, missing/invalid metadata, duplicate field, modified ciphertext or unsupported schema must never supply a usable connection.
- Restore happens locally on construction/restart. Connect, status, restore, forget, disconnect, navigation and refresh make no search, trace upload, AI request or provider validation request. Only the existing deliberate search/export actions may send data. Tests use synthetic credentials and offline transports; no paid qualification is implied.
- Tavily's persisted search reservations and usage-review gate remain authoritative. Reconnect, remember, forget, disconnect and restart never reset reservations, create a fresh allowance ledger, raise the approved absolute cap or erase failed/interrupted attempts. A restored limit below existing reservations cannot silently become a larger allowance. LangSmith export attempts and prior receipts remain intact.
- Forget removes only that service's remembered copy and keeps its current valid session connected. Disconnect clears that service's session and removes its remembered copy. Reconnecting with Remember unchecked removes any prior remembered copy before replacing the session. Other services remain unchanged. A failed deletion reports that the saved copy may remain and cannot report successful forgetting/disconnection of storage.
- An active Tavily search or LangSmith export blocks changing, forgetting or disconnecting that service until the request finishes. The active request uses a frozen key and metadata; a blocked change cannot modify its state, accounting or saved bytes. Existing Nebius active-investigation protections remain.
- Failed encryption, atomic replacement, decryption, unsupported-platform remembering and unavailable/linked/oversized storage produce controlled key-free errors. A failed remember or replacement preserves the prior valid connection and saved copy; it cannot silently downgrade to a session-only success. Failed restore leaves the workspace usable, exposes the recovery state, and makes no outbound call. Non-Windows session-only use remains available.
- Status/API responses expose only connection presence/source, remembering support/state, controlled errors and needed nonsecret settings. Keys, encrypted payloads and secret digests do not appear in responses, logs, project exports, receipts, browser storage, source artifacts or documentation. Validation errors cannot echo submitted keys. Inputs are cleared after requests and cannot populate Remember automatically.
- Strict route validation accepts the legacy session-only bodies, permits only the documented optional boolean Remember field, rejects unknown fields and wrong types, and protects connect/forget/disconnect with the existing local-origin checks. No new remote-access or hosting behavior is introduced.
- Existing backup/release exclusions remain: credentials, environment files and private logs are excluded. The stopped-app backup still contains only its existing allowlist, preserves the spending ledger and restores into a new directory. Optional remembered blobs are not portable backup artifacts.
- Verify synthetic end-to-end HTTP remember/restart/forget/disconnect for both optional services, service swapping/isolation, corrupt and wrong-metadata restoration, unsupported-platform and storage failures, active-request conflicts, strict route/origin handling, legacy Nebius restoration and absence of outbound calls. Verify visible controls/status/error recovery in the real local browser with the current build identity.
- Record before/after preservation of the founder's existing workspace/revisions, historical receipts and provider configuration without printing private content or reading real keys. No project reruns, historical source-hash changes, allowance changes, real searches or real uploads are authorized by E.

Delivery evidence belongs in Build E results with exact offline checks and browser observations. Pending checks, live qualification and independent human review must remain labeled pending. F hosting, additional provider integrations, physical validity, customer validation and final submission are outside this milestone.
