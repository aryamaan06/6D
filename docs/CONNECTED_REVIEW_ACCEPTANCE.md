# Connected review and interface polish acceptance

Authorized October 23, 2026. Third of the agreed five remaining builds.

An engineer opens one saved project context, sees current findings and evidence
gaps, follows the relevant calculation/playback/study/coverage or follow-up view,
and returns to the report without losing project/revision identity.

- A read-only overview captures canonical findings and supplemental evidence in
  one SQLite snapshot. It distinguishes no current calculation, unmet criteria,
  unassessed requirements, historical evidence and draft edits.
- Navigation groups existing capabilities, shows current location and provides
  contextual handoffs from findings to the appropriate calculation and Inspector.
  Overview/filters/navigation never run calculations or AI automatically.
- Show actual counts and evidence links, without a readiness score or claims of
  completeness. Coverage declarations and closed actions never become numerical
  passes. Bound history scans and disclose omissions.
- Preserve existing Canvas/Table/Reader, revision editing, model-specific views,
  simulations, study/import history, Assistant and full report/export functions.
- Refine spacing, visual hierarchy, charts and responsive navigation. Loading,
  error/retry and empty states stay clear; keyboard/focus controls remain usable.
- Display SI powers as superscripts while keeping stored/exported units, form
  values, source text, CSV and raw JSON unchanged.
- Verify snapshot consistency, canonical finding identity, no solver/provider
  calls, stale/context guards, actual browser handoffs, responsive layout and
  original workspace/history/configuration preservation. Use disposable data.
